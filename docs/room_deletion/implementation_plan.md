# ルーム削除機能の実装計画

自分が作成したルーム（オーナー権限を持つルーム）をトップページの一覧から削除できるようにします。

## 変更内容

### 1. トップページ ([app/page.tsx](file:///C:/Users/ntana/Documents/Antigravity_docs/istri/app/page.tsx))

- **型定義の更新**: `Room` 型に `ownerId` を追加。
- **データ取得の更新**: `onSnapshot` 内で `ownerId` も取得するようにキャストを調整。
- **削除関数の追加**: `handleDeleteRoom` 関数を実装し、Firebaseの `deleteDoc` を呼び出し。
- **UI調整**: ルームカード内に、自身がオーナーの場合のみ削除ボタンを表示。誤操作防止のため、削除前に `window.confirm` で確認を挟む。

### 2. 履歴の管理

- 履歴（最近いった場所）カードにも削除ボタン（×）を追加し、ローカルストレージから特定のルームを消せるように改善。

## 完了条件
- 自分が作成したルームのカードに削除ボタンが表示されること。
- 削除ボタンを押して確定すると、一覧から消え、Firestore上からも削除され、新しく作成枠が空くこと。
